## 🛠 Ferramentas, bibliotecas e frameworks

Python: Linguagem de programação ensinada no semestre letivo na disciplina de Introdução à Programação e utilizada pela biblioteca Pygame

Pygame-ce: Biblioteca externa do Python utilizada com a finalidade de facilitar o carregamento de imagens e áudios, sistematização da lógica de colisão e dos sprites, bem como da recepção dos inputs dos usuários

## 📚 Conceitos utilizados

Operadores Condicionais [if,elif,else]: foram aplicados com o objetivo de definir as múltiplas respostas do programa em decorrência das ações do jogador

Listas: aplicadas na lógica de armazenamento dos dados de posição, coleta e tipo dos objetos do jogo

Funções: empregadas para definir os comportamentos dos objetos dentro das classes

Laços de Repetição [for, while]: utilizados para estabelecer o loop principal de funcionamento do jogo, bem como para definir a mecânica de colisão dos objetos

Programação Orientada a Objetos e Modularização: adotadas de forma fundamental com a finalidade de modularizar o projeto. O encapsulamento desenvolvido por meio da disposição dos atributos dos objetos em classes permitiu melhor gerenciamento das características dos objetos via instanciamento
